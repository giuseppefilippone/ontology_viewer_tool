Browse and edit every entity of the workspace, Protégé style.

  • Sidebar — Classes / Individuals / Object / Data / Annotation properties / Datatypes; hierarchies with ▸ toggles, the filter box searches by name. Scope restricts the lists to the active ontology (default) or one module; with an inferred result the hierarchy can switch Asserted / Inferred.
  • Right click on any row — open, create child or sibling, rename IRI, duplicate, deprecate, delete, copy the sub-hierarchy as tab-indented text. Works on owl:Thing and the top properties too.
  • Entity page — Description / Annotations / Usage / Instances / Fuzzy panels; every + button opens the matching editor (types, assertions, expressions, annotations). Fuzzy membership plots are editable by dragging the shape handles ("save shape" = pending change).
  • History — Back / Forward over the visited entities (Alt+← / Alt+→, or the View menu).
  • Edits become pending changes (header chip): write them to the files with File → Save, revert with Undo / Discard.
