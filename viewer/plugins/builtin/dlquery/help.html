DL Query — Protégé-style class expressions in Manchester syntax, answered by the classic reasoner.

  • Type an expression (autocomplete offers entities and keywords: some, only, and, value…), pick the result sets (sub/super/equivalent classes, instances) and run.
  • Example: Territory and hasSeries some (Series and hasIndicator value poverty_index).
  • Results are entity links; fuzzy entities keep their colour.
