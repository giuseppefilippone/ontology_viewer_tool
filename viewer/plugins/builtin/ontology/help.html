Overview of the active ontology (the module chosen in the header bar) in three sub-tabs.

  • Overview — the ontology header: editable Ontology IRI and Version IRI (Enter or click away to apply), location, annotations (+ to add, ✕ to remove), direct and indirect imports (+ import from workspace, file or URL), prefixes (✎ renames a namespace in every module) and general class axioms.
  • Fuzzy annotation (Overview, header card) — the local name of the annotation property that marks fuzzy entities (default fuzzyLabel). Leave it empty to treat the workspace as a classical crisp ontology. Fuzziness also propagates through owl:equivalentClass / owl:equivalentProperty.
  • Metrics — OWL API-style metrics, Closure column (active ontology + imports) next to the Module column; "count annotations" includes/excludes annotation axioms.
  • Export — metrics as CSV, LaTeX or PDF (scope: module, closure, both or per-module breakdown).
