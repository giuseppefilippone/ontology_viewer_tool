Run the reasoners on the schema plus a chosen set of individuals.

  • Individuals — search and add the individuals to reason about (the schema is always included); the set is saved with the query set.
  • Fuzzy reasoner (fuzzy-dl-owl2 / FuzzyDL) — add query rows (instance, subsumption, satisfiability, related, defuzzify…), pick the MILP solver, Run. save query set / load saved set persist the rows per workspace and reload automatically.
  • Inferred view — classifies the TBox/RBox closure with HermiT or Pellet and shows what the reasoner adds; each inferred row can be asserted into a module. Drives the Inferred hierarchy of the Entities sidebar and the inferred sections of the entity pages.
  • Run history — every successful run is snapshotted; compare two runs of the same kind from Reasoner menu → Run history & diff….
