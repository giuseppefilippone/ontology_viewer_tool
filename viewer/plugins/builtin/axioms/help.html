The axioms of the active module, rendered in DL notation (crisp) or FuzzyDL syntax (fuzzy: degrees, membership functions, aggregations).

  • TBox / RBox come from the module file (anonymous expressions included), the ABox from the index in pages of 500; the search box filters the ABox.
  • Fuzzy axioms (involving fuzzy entities or carrying degrees) are dot-marked and use the reasoner's FuzzyDL syntax — the same the .fdl export produces.
  • Export — the shown axioms as CSV, LaTeX (standalone or fragment) or compiled PDF.
