Every fuzzy entity of the workspace, grouped by kind and shape.

  • An entity is fuzzy when it carries the fuzzy annotation (see Ontology Info → Fuzzy annotation, default fuzzyLabel) or when it is equivalent to an annotated entity — those show ≡ name with the annotated source.
  • Datatypes are grouped by membership-function shape (leftshoulder, triangular…), classes by concept type (weighted / OWA, bridge classes, composites).
  • Click any entry to open its entity page; the colour legend at the top distinguishes fuzzy from crisp entities everywhere in the app.
